# Chapter 11: Mesh Networks and Resilient Zombieproof Data Webs

## Introduction: Building the Network When the Grid Is Dead

Traditional radio links can fail—zombies bite cables and fences. Mesh networks create flexible, self-healing webs for radio comms that survive attacks, jamming, and broken equipment.

---

## What Is Mesh Networking?

- A decentralized network of nodes (radios) where each node routes data for the others.
- Nodes connect dynamically — if one path fails, signals reroute.
- Increases range, resilience, and redundancy for survivors’ communications.

---

## Key Features for Survivors

- **Self-configuring:** No central server needed, just working radios.
- **Fault-tolerant:** Can handle node failures or zombie destroyers.
- **Scalable:** Easily add or remove nodes during survival operations.
- **Secure:** Encryption and authentication options prevent hijacking.

---

## Popular Mesh Protocols

- **802.11s:** Wi-Fi mesh standard for local networks.
- **BATMAN (Better Approach To Mobile Adhoc Networking):** Optimized routing for mobile nodes.
- **OLSR (Optimized Link State Routing):** Uses routing tables and proactive messaging.
- **LoRa Mesh:** Long-range low power mesh for sensor networks.

---

## Implementing Mesh in the Field

- Use SDR or modular radios flashed with mesh-capable firmware.
- Combine with directional antennas for long hops.
- Experiment with open source tools: Meshtastic, cjdns, Serval Project.

---

## Protocol Abstraction Layers in Mesh

- Physical and link layers with frequency-agile radios.
- Routing protocols adapting realtime topology.
- Application layers for voice, text, or sensor data sharing.

---

## Practical Tips

- Start with small local meshes, expand as needed.
- Keep spare nodes ready to replace dead radios.
- Monitor network health and vary power to optimize battery life.

---

## Example Mesh Use Cases

- Emergency comms between bunkers.
- Sharing intelligence on zombie movements.
- Coordinating resource logistics in hostile zones.
