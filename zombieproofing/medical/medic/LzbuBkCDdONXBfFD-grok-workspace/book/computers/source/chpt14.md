# Zombieproof Computers: How to Keep a Mind When the Grid Is Gone

Chapter 14: Expanding and Securing the Network

You’ve got a functioning zombieproof computer, powered, cooled, and even talking with its peers. Now it’s time to think big—expanding your network and securing it against threats from both undead hackers and environmental damage.

This chapter explores scalable network topologies, advanced protocols for robust communication, plus encryption and access control for safe and survivor-approved digital exchanges.

Network Scalability
Mesh networks: Each node relays data, creating robust, redundant paths.

Star networks: Central node controls communication; easier but riskier.

Hybrid models: Combine mesh and star for balance of efficiency and resilience.

Advanced Protocols
Error correction codes (ECC) for reliable data in noisy environments.

Retransmission strategies and acknowledgments to guarantee delivery.

Routing protocols to handle multiple hops and network partitions.

Security Fundamentals
Encryption: Use simple symmetric ciphers or custom schemes for confidentiality.

Authentication: Devices verify each other with shared keys or challenge-response.

Access control: Restrict network resource use to trusted nodes only.

Survival Project: Securing Your Network
Implement handshake protocols ensuring only authorized devices join.

Encrypt messages with lightweight algorithms suitable for limited resources.

Log network events and monitor for suspicious activity with simple counters.

Environmental Hardening
Protect network cables and nodes against moisture, temperature, and shock.

Use ruggedized connectors and sealed enclosures.

Plan for redundant power supplies and backup communication lines.

With a secure, scalable network, your zombieproof computer community becomes a lifeline in the apocalypse—sharing knowledge, resources, and digital firepower.
